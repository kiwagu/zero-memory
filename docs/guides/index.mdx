Practical, task-oriented guides for working with the memory store.

[Briefings](/docs/guides/briefing) explains how a session opens with the right
context, and how the briefing pack is composed, budgeted, and kept free of
noise. [Recall quality](/docs/guides/recall-quality) covers how the system
learns which recalled memories were actually used, and feeds that back into
ranking.

[Import](/docs/guides/import) seeds the store from existing markdown
knowledge, or bootstraps it from a repository's docs and history.
[Export](/docs/guides/export) is memory-as-code: a deterministic markdown tree
you can read, diff, back up, and re-import.

[Session receipts](/docs/guides/session-receipt) are the one-line
end-of-session summary of what memory captured, what fired, and what it saved.
The [rules incubator](/docs/guides/rules-incubator) promotes proven memories
into standing rules, delivered through MCP, briefings, hooks, or instruction
files.
