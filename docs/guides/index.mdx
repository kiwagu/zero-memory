Practical, task-oriented guides for working with the memory store.

- [Briefings](/docs/guides/briefing) — how a session opens with the right
  context, and how the briefing pack is composed, budgeted, and kept free of
  noise.
- [Recall quality](/docs/guides/recall-quality) — how the system learns which
  recalled memories were actually used, and feeds that back into ranking.
- [Import](/docs/guides/import) — seed the store from existing markdown
  knowledge, or bootstrap it from a repository's docs and history.
- [Export](/docs/guides/export) — memory-as-code: a deterministic markdown
  tree you can read, diff, back up, and re-import.
- [Session receipts](/docs/guides/session-receipt) — the one-line
  end-of-session summary of what memory captured, what fired, and what it
  saved.
- [Rules incubator](/docs/guides/rules-incubator) — promote proven memories
  into standing rules, delivered through MCP, briefings, hooks, or
  instruction files.
